# Simple-Image-Editing-Tool
Simple Image Editing Tool using Python, OpenCV, and NumPy with image resizing, rotation, flipping, cropping, color channel operations, and image processing functionalities.

A beginner-friendly Computer Vision project developed using Python, OpenCV, and NumPy that performs basic image editing operations.

This project demonstrates how computers process and manipulate images using image arrays and OpenCV functions.

---

#  Features

##  Image Operations
- Read and display images
- Save processed images

## Image Transformations
- Resize images
- Rotate images
- Flip images
- Crop images

##  NumPy Operations
- Work with image arrays
- Create custom image arrays

##  Color Channel Processing
- Split RGB channels
- Merge color channels
